# 🚍 Análise de Mobilidade Urbana e Otimização de Tráfego com Apache Spark

Trabalho prático desenvolvido para a disciplina de Big Data do curso de Bacharelado em Sistemas de Informação. O objetivo deste projeto é aplicar os conceitos do ecossistema Apache Spark e PySpark na resolução de um problema real de processamento massivo de dados de geolocalização e trânsito.

---

## 📋 Sobre o Projeto
Empresas de logística e secretarias de transporte geram diariamente terabytes de dados de GPS de frotas e sensores de trânsito. Atrasos constantes e gargalos em horários de pico geram prejuízos operacionais e insatisfação. 

Neste projeto, construímos um pipeline de dados distribuído utilizando PySpark para mapear padrões de retenção de tráfego e calcular intervalos entre paradas, ajudando a otimizar o fluxo viário.
